# Ιχνηλασιμότητα πρόβλεψης

Η αλυσίδα τεκμηρίων είναι: πρωτότυπο workspace → Phase 2A recovery manifest → `artifacts/approved_reference/PROVENANCE.json` → run manifests → τελικά reports. Για κάθε εισαγόμενο αρχείο αποθηκεύονται original path, Phase 2A hash, imported path και imported hash. Τα frozen artifacts είναι read-only inputs· όλες οι νέες έξοδοι γράφονται στο `outputs/generated/`.

Το επιστημονικό συμβόλαιο παγώνει 11 systems, 9 physical sites, 934.800 canonical rows, 929.952 windows, 4 expanding folds, D+1/24 ώρες και 36.529 κοινές daylight observations. Οι πηγές ρυθμίσεων βρίσκονται στο `config/forecasting/` και ο αυθεντικός κώδικας στο `src/`.
